# Тема 5. Типи та характеристики SSD-накопичувачів. Діагностика диска в Windows

## Мета роботи
- Ознайомитися з типами, характеристиками та форм-факторами SSD.
- Навчитися отримувати технічну інформацію про встановлений накопичувач за допомогою PowerShell.
- Створити скрипт для автоматизованого збору даних про диск.

## 1. Типи та характеристики SSD-накопичувачів

### 1.1. Класифікація за типом пам'яті (NAND)

| Тип | Бітів на комірку | Опис |
| :--- | :--- | :--- |
| **SLC** (Single-Level Cell) | 1 | Найвища швидкість та довговічність, висока ціна. Використовується в серверах. |
| **MLC** (Multi-Level Cell) | 2 | Баланс продуктивності та ціни. Зустрічається в робочих станціях. |
| **TLC** (Triple-Level Cell) | 3 | Найпоширеніший тип для звичайних ПК та ноутбуків. |
| **QLC** (Quad-Level Cell) | 4 | Найбільша ємність, низька вартість, але менший ресурс. Підходить для зберігання даних. |

![](https://geeks.news/uploads/posts/2022-04/nand.webp)

### 1.2. Форм-фактори SSD

**2,5-дюймовий SSD**
- Інтерфейс: SATA III
- Швидкість: до 550 МБ/с
- Типовий зовнішній вигляд: прямокутний металевий корпус, як у ноутбучного HDD.

   ![](https://www.oscoo.com/wp-content/uploads/2024/11/OS002-2.5-inch-SATA-SSD-02.webp)

**M.2 SSD**
- Інтерфейс: SATA III або PCIe NVMe
- Швидкість: до 7000+ МБ/с (NVMe)
- Компактна плата, встановлюється безпосередньо в материнську плату.

![](https://img.telemart.ua/848533-1096302/amd-radeon-r3-3d-nand-512gb-m2-2280-sata-r3ms0512g8.png)

**PCIe SSD (карта розширення)**
- Інтерфейс: PCIe
- Використовується в серверах та робочих станціях для максимальної продуктивності.

![](https://img.joomcdn.net/193dc358fcad41211fa087dcff4caba96e354bcd_original.jpeg)

### 1.3. Протоколи передачі даних

| Протокол | Опис |
| :--- | :--- |
| **SATA** | Застарілий протокол, створений для HDD. Обмежує швидкість SSD до ~550 МБ/с. |
| **NVMe** | Сучасний протокол, розроблений для флеш-пам'яті. Використовує лінії PCIe, забезпечує високу швидкість та низькі затримки. |

## 2. Скрипт для відображення технічної інформації про накопичувач

Для отримання даних про диск у Windows використаємо вбудовані можливості **PowerShell**. Скрипт нижче збирає інформацію про фізичний диск, його модель, тип, інтерфейс, серійний номер, температуру, знос та літери томів.

### 2.1. Вимоги
- ОС Windows 10/11
- PowerShell має бути запущений **від імені адміністратора**

### 2.2. Код скрипта `Get-DiskInfo.ps1`

```powershell
<#
.SYNOPSIS
    Отримує технічну інформацію про встановлені накопичувачі (SSD/HDD)
.DESCRIPTION
    Скрипт показує модель, тип носія, інтерфейс, серійний номер, літеру тому, температуру та знос дисків.
.NOTES
    Запускати від імені адміністратора
#>

# Перевірка прав адміністратора
if (-NOT ([Security.Principal.WindowsPrincipal] [Security.Principal.WindowsIdentity]::GetCurrent()).IsInRole([Security.Principal.WindowsBuiltInRole]::Administrator)) {
    Write-Host "Помилка: Скрипт потрібно запускати від імені адміністратора!" -ForegroundColor Red
    pause
    exit 1
}

Write-Host "Збір інформації про накопичувачі..." -ForegroundColor Green

# Отримуємо фізичні диски (виключаючи USB та віртуальні)
$physicalDisks = Get-PhysicalDisk | Where-Object {
    $_.BusType -notlike "*USB*" -and
    $_.BusType -notlike "File Backed Virtual"
}

# Отримуємо розділи з літерами
$partitions = Get-Partition | Where-Object { $_.DriveLetter } | Select-Object DriveLetter, DiskNumber

# Отримуємо дані про надійність (температура, знос)
$reliability = Get-PhysicalDisk | Get-StorageReliabilityCounter

# Формуємо результат
$result = foreach ($disk in $physicalDisks) {
    $partition = $partitions | Where-Object { $_.DiskNumber -eq $disk.DeviceId }
    $reliable = $reliability | Where-Object { $_.DeviceId -eq $disk.DeviceId }
    
    # Конвертуємо розмір у ГБ
    $sizeGB = if ($disk.Size) { [math]::Round($disk.Size / 1GB, 2) } else { "N/A" }
    
    # Виводимо інформацію
    [PSCustomObject]@{
        "Номер диска" = $disk.DeviceId
        "Модель" = $disk.FriendlyName
        "Тип носія" = $disk.MediaType
        "Інтерфейс" = $disk.BusType
        "Серійний номер" = $disk.SerialNumber
        "Розмір (ГБ)" = $sizeGB
        "Температура (°C)" = if ($reliable.Temperature) { $reliable.Temperature } else { "N/A" }
        "Помилки читання" = if ($reliable.ReadErrorsTotal) { $reliable.ReadErrorsTotal } else { 0 }
        "Знос (Wear)" = if ($reliable.Wear -ne $null) { $reliable.Wear } else { "N/A" }
        "Літера тому" = if ($partition) { ($partition.DriveLetter -join ', ') + ':' } else { "—" }
    }
}

# Виводимо таблицю
Write-Host "`nІнформація про накопичувачі:" -ForegroundColor Cyan
$result | Format-Table -AutoSize

pause

## Висновки

1. SSD класифікуються за типом пам'яті (`SLC`, `MLC`, `TLC`, `QLC`) та форм-фактором (`2,5"`, `M.2`, `PCIe`). Найпоширеніший для сучасних ПК — **M.2 NVMe** з пам'яттю **TLC**.
2. **PowerShell** дозволяє отримати детальну технічну інформацію про диск нативними засобами ОС, без використання додаткових сторонніх програм.
3. Скрипт `Get-DiskInfo.ps1` успішно автоматизує збір усіх важливих параметрів для діагностики стану накопичувача.
